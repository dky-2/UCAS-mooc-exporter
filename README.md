# UCAS-mooc-exporter

国科大在线学生作业附件导出入口：将**国科大在线「我教的课」全部学生提交附件**批量导出，按你指定的格式、命名和路径整理好落到本地。

> 面向教师用户。整个流程对课程站点只做「查看 + 创建一次导出任务」，不会改动成绩，不会提交或打回任何学生作业。

---

## 主要功能

- 在课程作业列表里定位指定的某一次作业（如「第二次作业」）。
- 触发平台自带的批量导出（「导出提交附件」），拿到全部已交学生的提交文件。
- 按你要求的**文件格式**筛选（默认只留 PDF），按你要求的**命名形式**重命名，存到你指定的**路径**。
- 自动完成解压 → 筛选 → 重命名 → 清理中间文件 → 数量校验（文件数应等于「已交」人数）。

## 安全边界

- 不批改、不打分、不提交、不打回作业。
- 不代替你登录：账号密码或扫码由你本人在浏览器窗口完成。
- 不处理「未交」学生。

## 安装

把本仓库放进 Codex 的 skills 目录即可。**注意目录名用小写** `ucas-mooc-exporter`（skill 标识要求小写连字符）。

**方式一：git clone（推荐）**

```powershell
git clone https://github.com/<你的用户名>/UCAS-mooc-exporter.git "$env:USERPROFILE\.codex\skills\ucas-mooc-exporter"
```

**方式二：手动复制**

把本仓库文件夹复制到 `%USERPROFILE%\.codex\skills\` 下，并重命名为 `ucas-mooc-exporter`。

**方式三：不用安装**

直接把本仓库路径交给 Codex，并在提示里指明使用该目录下的 `SKILL.md`。

安装后**新开一个 Codex 任务**（技能列表在会话启动时载入），即可用 `$ucas-mooc-exporter` 调用。

## 使用

用自然语言说出你的四个要求即可，缺省项会自动用默认值：

> 用 $ucas-mooc-exporter，把第二次作业的学生提交附件导出来，只要 PDF，
> 命名成「姓名-学号-第二次作业」，放到 `D:\作业导出`。

或者最简形式：

> 用 $ucas-mooc-exporter 导出第一次作业的提交附件。

## 工作流程（skill 内部做什么）

1. 打开课程首页 →「作业」，找到目标作业，记下其 `workid` 与「已交」人数。
2. 打开该作业的批阅页。
3. 点「更多 → 导出作业附件 → 导出提交附件 → 确定」，在平台侧生成打包任务。
4. 回课程首页「下载中心」等待状态变为「导出成功」。
5. 读出该条目的 CDN 直链并下载压缩包到目标路径。
6. 运行 `scripts/collect-attachments.ps1`：展开两级压缩包 → 按格式筛选 → 按模板重命名 → 清理中间文件 → 打印校验结果。

对站点有只读性质：仅查看页面 + 创建一次导出任务。

## 单独使用整理脚本

脚本可以脱离 skill 单独跑。输入是平台「导出提交附件」得到的压缩包：

```powershell
.\scripts\collect-attachments.ps1 `
  -ZipPath 'D:\作业导出\班级123456-第二次作业(附件).zip' `
  -OutDir  'D:\作业导出' `
  -Label   '第二次作业' `
  -Extension .pdf `
  -NameTemplate '{name}-{sid}-{label}'
```

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `-ZipPath` | 是 | | 外层压缩包路径 |
| `-OutDir` | 是 | | 成品目录，只保留筛选后的文件 |
| `-Label` | 是 | | 作业标识，用于 `{label}` |
| `-Extension` | 否 | `.pdf` | 可多个；`*` 表示全部保留 |
| `-NameTemplate` | 否 | `{name}-{sid}` | 支持 `{name}` `{sid}` `{label}` |
| `-KeepArchives` | 否 | 关 | 保留临时解压目录 |
| `-RemoveSourceZip` | 否 | 关 | 整理完成后删除外层压缩包 |

行为约定：

- 同一学生有多个匹配文件时自动追加 `-1`、`-2`。
- 目标文件重名时追加 `_2`、`_3`，不会覆盖已有文件。
- 某位学生没有匹配格式的文件时给出告警，并列出其实际提交的扩展名。
- 完成后打印成品目录里「非目标格式文件」的数量，便于确认目录是否干净。

## 常见问题

| 现象 | 处理 |
|---|---|
| 打开课程页跳到登录页 | 自动化浏览器与你本机浏览器不共享登录态，需要你本人在弹出的窗口登录一次 |
| 点了「确定」却没有任何下载 | 正常：产物在课程首页「下载中心」里排队生成，等待「导出成功」后取直链 |
| 提示浏览器 chrome / edge 不可用 | 该环境只提供 Codex 内置浏览器，属正常限制 |
| 下载直链 403 / 失败 | 直链令牌是一次性的，重新打开「下载中心」取一次新链接 |
| 某位学生的文件没出现在结果里 | 他提交的不是目标格式，脚本会在告警里列出实际格式 |

更完整的站点细节与故障对照见 [references/platform-notes.md](references/platform-notes.md)。
